# 0011. App-generated, time-sortable text ids

Status: Accepted

## Context

SQLite `rowid` tie-breaks and autoincrement do not exist in PostgreSQL, and rows should move between engines unchanged.

## Decision

`newId(prefix)` = prefix + base-36 milliseconds + counter + random bytes. Within a process ids sort in creation order, so `ORDER BY created_at, id` and keyset cursors `(created_at, id)` replace `rowid`.

## Alternatives considered

UUIDv4 (no order); UUIDv7 (equivalent, longer); database sequences (engine-specific, leak counts).

## Consequences

Order across processes within one millisecond is arbitrary (only used as a tie-break). Ids are not secrets.
