# 0006. Optional Cloudflare Worker with a signed resolve endpoint that fails closed

Status: Accepted

## Context

Pages should be served from a global cache and survive origin outages, but the origin must remain correct without the edge.

## Decision

The Worker caches by host + path, serves stale-while-revalidate and stale-if-error, and asks the origin through `/internal/edge/resolve` with an HMAC over timestamp, nonce, method and path. The origin refuses all edge calls without `EDGE_SHARED_SECRET`. Purge by URL on every change. The origin can serve everything itself.

## Alternatives considered

Cloudflare cache rules only (no stale-if-error control, no signed contract); a Worker that talks to the database (second source of truth).

## Consequences

Two implementations of routing to keep consistent (`resolveLive` is shared by both paths). Worker behaviour is tested with fakes, not workerd.
